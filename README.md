# Fibonacci in four methods

Implement Fibonacci series in dynamic programming (memoization)(O(n)),bnottom-up approach (O(n)), naive version (2^n) and matrix eponentiation technique (log(n))

## Tech stack

- Python 3

## Contents

- `bottom_up.py`: functions `Fib_bottom_up`
- `matrix_exponentiation.py`: functions `multiply_matrix`, `power_matrix`
- `memozation.py`: functions `fibonacci_mem`
- `naive_version.py`: functions `fibonacci_naive`

## How to run

Requirements: Python 3.

```bash
python <file>.py
```
